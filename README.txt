Wi‑Fi «Детская Дима» — Landing Page

Назначение:
Эту страницу нужно разместить на публичном HTTPS-адресе.
После этого адрес страницы указывается в ASUS Guest Portal в поле
Landing Page / Redirect URL.

Сценарий:
1. Телефон подключается к Guest Wi-Fi.
2. ASUS показывает captive portal.
3. Пользователь нажимает «Продолжить».
4. ASUS разрешает интернет.
5. ASUS перенаправляет браузер на этот сайт.

Файл:
index.html — автономный сайт, внешних картинок/библиотек не требует.

Для размещения достаточно любого веб-сервера с HTTPS:
Nginx, Caddy, GitHub Pages, Cloudflare Pages и т.п.
